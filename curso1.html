Desarrollo web

Curso de Desarrollo Full-Stack

Aprende a desarrollar aplicaciones web completas, desde el frontend hasta el backend, y termina con un producto real desplegado en producción.

24 semanas Nivel intermedio Online en directo Próxima edición: enero

Domina el stack completo

Este curso está diseñado para quienes quieren construir productos web de principio a fin. Trabajarás con las tecnologías más demandadas y aprenderás a pensar como un ingeniero de producto: requisitos, arquitectura, implementación, pruebas y despliegue.

No necesitas experiencia previa en programación, pero sí constancia: dedicamos entre 8 y 10 horas semanales a clases, retos y proyecto.

  • Frontend moderno con HTML, CSS, JavaScript y React.
  • Backend con Node.js, Express y APIs REST.
  • Bases de datos SQL y NoSQL.
  • Despliegue, mantenimiento y buenas prácticas.

Contenido del curso

Seis módulos progresivos, cada uno con clases en directo, retos semanales y una entrega evaluada.

  1. Introducción al desarrollo web: cómo funciona la web, herramientas y primer proyecto.
  2. HTML semántico y CSS moderno: maquetación responsive, flexbox, grid y accesibilidad.
  3. JavaScript esencial: lógica, DOM, asincronía y consumo de APIs.
  4. Frameworks de frontend: componentes, estado y rutas con React.
  5. Backend con Node.js y Express: autenticación, APIs y bases de datos.
  6. Despliegue y mantenimiento: CI/CD, monitorización y optimización.

Al finalizar el curso

Habrás construido una aplicación full-stack completa con autenticación, base de datos y despliegue. Tendrás las habilidades necesarias para optar a puestos de desarrollador junior y un portafolio con el que demostrarlo.

Proyecto final Diseña, desarrolla y presenta una aplicación real ante tus mentores y compañeros. Recibirás feedback técnico y de producto.
